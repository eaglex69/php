# Crownfall — версия PHP 8 + MySQL + AJAX + Canvas

Та же игра, что и версия на Next.js: регистрация, колода из 8 карт, 122 карты, сундуки, косметика (облики башен, знамёна, эмоции),
кланы, друзья, общий и клановый чат, просьбы о фрагментах, ежедневные подарки, лиги с ежемесячным сбросом, еженедельные турниры,
PvP-арена с реальными игроками, арены со сложностью и полноценная админ-панель.
Бой рисуется на Canvas тем же движком, что и в Next.js-версии (`js/engine.js`). Фреймворков нет: чистый PHP, PDO и JavaScript (fetch/AJAX).

## Требования
- PHP 8.1+ с расширениями `pdo_mysql`, `mbstring` (необязательно — есть запасные функции), `fileinfo` не нужен
- MySQL 8 или MariaDB 10.4+
- Apache (mod_rewrite не нужен) или nginx + php-fpm

## Установка за 3 шага
1. Распакуйте архив в папку сайта (например, `/var/www/html/crownfall`). Дайте PHP право записи в папки `uploads/` и `data/`.
2. Откройте в браузере `http://ваш-сайт/crownfall/install.php`, введите данные MySQL (базу установщик создаст сам). Он создаст `config.php`, 21 таблицу и загрузит карты, лиги, арены и косметику.
3. Откройте `index.php` и зарегистрируйтесь — **первый игрок становится администратором**. Админ-панель находится в боковом меню.

После установки появится файл `data/installed.lock` — он закрывает установщик. Для повторной установки удалите его и `config.php`.

## Безопасность
- Пароли хранятся через `password_hash` (bcrypt), запросы к БД — только через подготовленные выражения PDO.
- Изменяющие запросы принимаются только с заголовком `X-Requested-With: fetch` (защита от CSRF) и сессионной cookie `SameSite=Lax`.
- Папки `lib/` и `data/` закрыты `.htaccess` (Apache). **Для nginx** добавьте:
  ```
  location ~ ^/(lib|data)/ { deny all; }
  location ~ ^/uploads/.*\.php$ { deny all; }
  location = /config.php { deny all; }
  ```
- Загруженные картинки проверяются по сигнатуре файла (PNG/JPG/WEBP/GIF до 4 МБ) и получают случайные имена; выполнение PHP в `uploads/` запрещено.
- Если лимит `upload_max_filesize` в php.ini меньше 2 МБ — увеличьте его (браузер заранее уменьшает фото до 640 пикселей, так что обычно хватает и 1 МБ).

## Структура
```
index.php      оболочка приложения          api.php        единый JSON-API (auth, game, chat, admin, upload)
install.php    установщик                    schema.sql     схема MySQL
lib/           ядро: БД, правила, сундуки, лиги, турниры, действия игры, админка
js/app.js      интерфейс (страницы, модальные окна)   js/battle.js   бой на Canvas   js/admin.js   админ-панель
js/engine.js   боевой движок и отрисовка (собран из TypeScript-исходников Next.js-версии)
css/app.css    стили (те же, что в Next.js-версии)   images/ картинки   uploads/ загрузки   data/catalog.json каталог карт
```

## Обновление каталога карт
Каталог в `data/catalog.json` создаётся из исходников Next.js-версии командой `node scripts/build-php-assets.mjs`
(она же пересобирает `js/engine.js`, `css/app.css` и картинки). Новые карты подхватываются автоматически при смене версии каталога.
